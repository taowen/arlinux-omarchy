Arlinux Omarchy

Omarchy 桌面运行于 Android，基础发行版为 Arch Linux ARM。
Super + Enter 打开终端；Super + 数字切换工作区；Alt + F4 关闭窗口。
快捷键使用实体键盘输入。

安装软件：pacman -Syu，然后 pacman -S 软件包名。
默认提供 Arch Linux ARM 和 Arch Linux 中文社区源，使用清华镜像。

Omarchy 源码：/usr/share/omarchy
个人配置：~/.config/omarchy 和 ~/.config/hypr
当前主题：~/.local/state/omarchy/current/theme
桌面日志：$XDG_RUNTIME_DIR/omarchy-shell.log

Android 管理设备网络、锁屏和服务生命周期。本产品使用独立的应用数据目录。
